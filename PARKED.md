# PARKED

Ideas deferred so that one thing can finish: the PDX-1i daily brief, running
unattended for thirty consecutive days. The finish condition is in
[SHIPPING.md](SHIPPING.md).

Parked is not cancelled. Each item below carries the condition that would
justify picking it back up. For nearly all of them that condition is the same,
because the count is the product: **the run count reaches thirty.** Resuming
anything here before then resets nothing and costs the count.

Adding to this list is the correct response to a good idea arriving mid-script.
One line, the date, and what would justify resuming it — then back to the script.
